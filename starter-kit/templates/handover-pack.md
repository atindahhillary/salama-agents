# Handover pack

What must survive staff turnover, for each agent and system (SAFE-A AD-4). Keep it where the deputy and the director can find it, and update it whenever something changes.

- [ ] Job card, current and signed
- [ ] Owner and deputy named, and the deputy has done the task at least once
- [ ] Every login is a named account; no single-person passwords; recovery set to a work address
- [ ] Where secrets are stored, and who can rotate them
- [ ] Step-by-step guide for the task, including the manual fallback when the internet or the AI service fails (AD-1)
- [ ] Latest evaluation report and the evaluation cases
- [ ] Breach plan and kill switch instructions
- [ ] Residency record and privacy risk check
- [ ] Supplier contacts, contracts and renewal dates
- [ ] Data costs: who pays for bundles or devices, and from which budget line (AD-2)
